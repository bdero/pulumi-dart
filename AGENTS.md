## Project
We are implementing a Dart language backend for Pulumi.
Refer to the [implementation plan](PULUMI_DART_PLAN_V2.md) for disambiguating project goals.

## Work tracking
This project uses thicket to track work items. Run `thicket quickstart` for a quick introduction on how to use thicket.

## Readme
Keep [the readme](README.md) up-to-date with instructions on how to build, test, run the project.

## Testing
Write automated tests whenever changing behavior. Goal is at least 80% test coverage.
After making any change, always be sure to run all of the tests to verify that everything is working.

## Cleanup
Remember that this is a git repository. Be sure to run `git status` to check for residual generated files and add them to .gitignore if necessary.
